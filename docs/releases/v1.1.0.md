# CharacterVault 1.1.0

Orion chat is faster and easier to live with. Plus a few quality-of-life polish items.

**Try it:** https://vault.charactervault.app  
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Orion
- Streaming feels lighter on long replies
- Stopping mid-reply keeps what Orion already wrote
- Desktop chat panel is resizable (width is remembered)
- Scroll follows new tokens until you scroll up
- Delete a message (with confirm) and trim everything after it
- Safer rendering when models include light HTML in replies

### Elsewhere
- Snapshot history is easier to use on phones
- Theme-aware tags and Feeling Lucky vortex
- Privacy notice linked from the app and docs

---

## Upgrade

Client-only app. Open the hosted site or rebuild locally; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Local data from 1.0.0 should keep working. Hard refresh if the UI looks stale after deploy.
