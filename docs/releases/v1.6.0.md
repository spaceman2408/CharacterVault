# CharacterVault 1.6.0

This release adds a **full vault backup** (cards, lorebooks, and settings) you can restore later, a **Settings backup** tab, and editor quality-of-life: save status, live counts, duplicate greetings and lorebook entries, and a save shortcut.

**Try it:** https://vault.charactervault.app  
**Staging:** https://staging.charactervault.app  
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Full vault backup and restore

Library header **Backup** now packs the whole vault, not only character cards.

- **ZIP contents** — cards under `characters/` (PNG with an image, JSON without), standalone lorebooks under `lorebooks/`, plus `settings.json` and `manifest.json`.
- **API keys** — off by default. Check **Include API keys** only when you are moving your own setup between browsers. That file can spend your AI quota; keep it private.
- **Restore** — **Import** a `.zip` (or drop it on the library). A preview lists cards, lorebooks, and whether settings (and keys) are present. Confirm to import.
- **Cards and lorebooks are copies.** Nothing already in the vault is deleted. Settings in a full backup **do** replace settings on this device.
- Older cards-only ZIPs still restore as content only.

Not in the ZIP: Orion/Agent chats, custom AI context, snapshots, and lorebook **links**. Linked books restore as separate cards and books; re-attach after if you need the link.

[Import & Export → Vault backup](/features/import-export#vault-backup) · [Vault Organization](/features/vault-organization)

### Settings backup

**Settings → Backup** exports AI config, sampler, prompts, studio (including favorite tags), workspace, and layout as JSON — without touching cards.

- Export uses **saved** settings. Save first if you changed anything.
- **Include API keys** is the same opt-in as vault backup.
- Import **stages a draft**. Review the tabs, then **Save Settings** to apply. A backup without keys keeps the keys already on this device.

[AI Setup → Backup](/configuration/ai-setup#backup-tab)

### Editor quality-of-life

- **Save status** in the character workspace header: **Saving…**, **Saved**, **Unsaved**, or **Save failed**. Failed saves stay local and retry on the next change.
- **`Ctrl+S` / `⌘+S`** flushes pending editor saves (including a lorebook draft) instead of the browser’s Save Page dialog.
- **Live counts** on section headers: characters, words, and an estimated token count as you type.
- **Extensions** is a JSON editor. Invalid JSON shows a warning and is **not** written; empty JSON saves as `{}`.

[Text Editor](/features/editor)

### Greetings and lorebook

- **Greetings** — **Duplicate** (confirm, then insert a copy right after) and **move up/down**.
- **Lorebook entries** — **Duplicate** (confirm). The copy gets the next available entry ID and lands after the original.

[Greetings Editor](/features/greetings-editor) · [Lorebook Editor](/features/lorebook-editor)

### Also in this release

- Card token chips show **active / total**. Click for a breakdown. **Total** is chat-relevant text only (active fields plus greetings and lorebook), not creator notes, tags, or other metadata.
- Deletes, replacements, and duplicates use in-app confirm dialogs. Failures use toasts instead of browser `alert` / `confirm`.

## Upgrade

Client-only app. Open the hosted site or rebuild locally; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Local data from 1.5.0 keeps working. Hard refresh if the UI looks stale after deploy.

A 1.5.x (or older) cards-only ZIP still restores. Prefer a new full backup if you want lorebooks and settings in the same archive.
