# CharacterVault 1.2.0

Paste your own notes into AI context without stuffing them onto the card. Plus clearer lorebook context controls and smarter sampler defaults.

**Try it:** https://spaceman2408.github.io/CharacterVault  
**Docs:** https://spaceman2408.github.io/CharacterVault/docs/

---

## Highlights

### Custom Context
- **AI Context → Custom** — paste free-text notes for the character you’re editing
- Toggle include on or off without deleting the text
- Feeds **Orion** and the **AI toolbar** (when enabled)
- Stays in this browser only — not on the card, not in PNG/JSON export, not in SillyTavern fields
- Token usage counts toward the panel estimate, with soft warnings for huge pastes

### Lorebook
- **Enable All / Disable All** for context lives next to the entry list (no need to open book settings)

### Sampler defaults and presets
- New installs: streaming, reasoning, and show reasoning **on** by default
- Default samplers start **neutral** (including top-k off) with **8K** context
- Quick presets **Creative / Balanced / Factual** updated to a modern min-p–first stack
- Applying a preset no longer overwrites your context length

### Small polish
- Vault cards without art show a single **No image** label (no duplicate badge)

## Upgrade

Client-only app. Open the hosted site or rebuild locally; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Local data from 1.1.0 should keep working. Hard refresh if the UI looks stale after deploy.

**Note:** Existing AI settings you already saved keep their values. The new streaming / sampler defaults apply to fresh installs and “reset to defaults.”
