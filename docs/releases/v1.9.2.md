# CharacterVault 1.9.2

CharacterVault 1.9.2 makes the Creator Notes preview render the way SillyTavern does, with preview controls, a resizable Dock, and CSS tools. The editor keeps your cursor, scroll, and undo when you switch sections, wraps a selection when you type `*` or `"`, and fits phones with the keyboard open. Plus OpenAI and Google Gemini presets, a simpler Sampler, native-only Agent tool calls, and a fix for absurd tokens-per-second readings.

**Try it:** https://vault.charactervault.app
**Staging:** https://staging.charactervault.app
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Creator Notes that render like SillyTavern

**Creator Notes → Preview** now shows the notes the way SillyTavern renders them. **Match SillyTavern** is on by default: Markdown is converted, `{{char}}` and `{{user}}` are filled in, styles on `:root` or `body` stop working, and remote images are hidden. A short list above the preview says what it changed. Turn the switch off to see the raw HTML and CSS.

- **Preview controls** — **Width** (Full, Wide, SillyTavern panel at 480px, Phone), a Dark, Light, or checkerboard **Background**, **Replay** for CSS animations, and **Remote media** to show remote images. Your choices are remembered in this browser.
- **Resizable Dock** — **Dock** puts the editor and preview side by side. Drag the divider, or double-click it or click **Reset dock size** to go back to half and half. Each character stays docked while the workspace is open.
- **Insert** — five starter snippets (Hero banner, Gradient title, Info block, Collapsible spoiler, Content warnings) land at the cursor with `{{char}}` where the name goes. **Ctrl+Z** removes one.
- **Color swatches** — click the swatch in front of a color in `<style>` or `style=""` to pick a new one. It keeps its format (hex, `rgb()`, `hsl()`), and **Ctrl+Z** undoes the pick in one step.
- **Format and size** — **Format** tidies the CSS in `<style>` blocks and leaves the HTML alone. The line under the heading shows the notes' size and any embedded `data:` images.

[Creator Notes → Match SillyTavern](/features/creator-notes#match-sillytavern)

### The editor keeps your place

Switch to another section and back: your cursor, scroll position, and undo history are where you left them. Changes from the Agent, Orion, or a snapshot rollback no longer land in your undo history, so **Ctrl+Z** only undoes your own edits.

- **Wrap on type** — select text and type `*` to get `*action*` (a second `*` makes `**bold**`), or `"` to get `"dialogue"`.
- **Ctrl+D** — selects the next match of the selection instead of opening the browser's bookmark dialog.
- **Editor Controls** — a new docs page lists every shortcut and typing helper, with Windows and Mac keys.

[Editor Controls](/features/editor-controls)

### Phone editing that fits

- **No focus zoom** — tapping into a field on an iPhone no longer zooms the page. Pinch-zoom still works.
- **Toolbars that fit** — the find bar puts Find and Replace on full-width rows, and the AI toolbar keeps its AI buttons and **More** on the first row with the search and format tools on a second.
- **Room to type** — with the keyboard open, the top header, the section bar, and the field heading hide so several lines of text stay visible. In greetings and lorebook entries the token count and **Enabled** / **Constant** toggles hide too. Everything comes back when the keyboard closes.

[Editor & AI Toolkit](/features/editor)

### Also in this release

- **OpenAI and Google Gemini presets** in **Settings → AI Config → API Base URL**. Gemini has a free tier.
- **Native tool calls only for the Agent**: the XML tool mode and the **Native** / **XML** chip are gone. A model that rejects tools stops the run with a clear error.
- **Simpler Sampler**: **Settings → Sampler** keeps Temperature, Top P, Max Tokens, and Context Length. Min P, Top K, and Repetition Penalty are removed, since most providers ignore or reject them. The second card is now **Output & Context**.
- **Cache hit or miss**: the info button on a reply shows **Cache: hit** with the cached token count, or **miss**, instead of a percentage.

## Fixes

- **Tokens per second**: tool-only and short replies no longer show 0 or thousands of t/s. Speed is left out under 20 tokens.

## Upgrade

Client-only app. Open the hosted site, rebuild locally, or rebuild the Docker image; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Running it with Docker? Pull and rebuild the image:

```bash
git pull
docker compose up -d --build
```

Local data from 1.9.1 keeps working. Hard refresh if the UI looks stale after deploy.
