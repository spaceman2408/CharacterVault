# CharacterVault 1.8.4

CharacterVault 1.8.4 lets you pin and rank OpenRouter hosts, keep prompts private or stick to free models with new OpenRouter Options, keep Exacto on for Agent tool calls, and merge a library lorebook into a character's own entries, plus a fix for typing spaces in book names.

**Try it:** https://vault.charactervault.app
**Staging:** https://staging.charactervault.app
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### OpenRouter host control

Choose which host serves an OpenRouter model, and in what order OpenRouter tries the rest.

- **Pin a host per model**: the **Provider** control under the model picker lists each host OpenRouter offers for that model. Tags such as `fp8`, `bf16`, or a region tell copies of the same host apart. The pin is saved per model.
- **Only use this host**: off by default, so OpenRouter falls back when the pinned host is down. Turn it on to fail the request instead.
- **Host priority**: **Settings → AI Config → OpenRouter Options → Host priority** picks **Balanced** (default), **Cheapest**, **Fastest**, or **Quickest start**. A pinned host still wins.
- **See who answered**: a reply's stats info shows the host that actually served it.

[AI Setup → Provider on OpenRouter](/configuration/ai-setup#on-openrouter)

### OpenRouter privacy and model filters

**Settings → AI Config → OpenRouter Options** adds three switches, all off by default. Your openrouter.ai account settings still apply on top of them.

- **No training on prompts**: skips hosts that may store and train on your prompts.
- **Zero data retention only**: uses only hosts that never store prompts, and model lists hide models with no such host.
- **Free models only**: model lists show only $0 models. Requests are unchanged.
- **Models your key can use**: with an OpenRouter API key, model lists leave out models blocked by your guardrails, ignored providers, or privacy settings.
- **Clear errors**: when no host passes these options, the error says which option blocked the request.

[AI Setup → OpenRouter Options](/configuration/ai-setup#openrouter-options)

### Exacto for the Agent

**OpenRouter Options → Always use Exacto for the Agent** is off by default. Turn it on and Agent tool calls use the model's `:exacto` variant even when a **Host priority** is set. Orion and the AI toolbar still follow the priority. Without it, any priority other than **Balanced** turns off OpenRouter's Auto Exacto.

[AI Setup → Exacto and the Agent](/configuration/ai-setup#exacto-and-the-agent)

### Merge a library book into a character

On a character with lorebook entries, **Character → Lorebook → Attach** (or **Copy** on a linked book) now offers **Merge** next to **Replace**.

- **Merge** keeps the character's entries and settings, adds the book's entries after them, and unlinks the book, so the shared book and its other characters stay as they were.
- **Open in vault** then makes a new library book from the merged entries.
- **Replace** works as before.

[Lorebook Vault → Merge into existing entries](/features/lorebook-vault#merge-into-existing-entries)

## Upgrade

Client-only app. Open the hosted site, rebuild locally, or rebuild the Docker image; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Running it with Docker? Pull and rebuild the image:

```bash
git pull
docker compose up -d --build
```

Local data from 1.8.3 keeps working. OpenRouter options and pinned hosts save with your AI settings and are included in settings backups. Hard refresh if the UI looks stale after deploy.
