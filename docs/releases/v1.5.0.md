# CharacterVault 1.5.0

This release rebuilds **AI Creation Studio** and adds an optional **Agent review diff**. Studio generations are now yours to prompt, trim, and tag. Agent writes can sit in a word-level diff until you approve them.

**Try it:** https://vault.charactervault.app  
**Staging:** https://staging.charactervault.app  
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### AI Creation Studio

The studio still turns a concept or tags into a card. Settings now control **which fields** run, **how they are prompted**, and **which tags** you see.

- **Field toggles** — Name and Description always generate. Turn **First Message** and **Examples** off independently to skip those calls.
- **Custom prompts** — **Settings → Creation Studio → Generation Prompts** edits the system, name, description, first message, and examples templates. Required placeholders (`${concept}`, `${name}`, `${description}`) are checked on save. Optional `${styleBlock}` and `${narrationRule}` inject perspective/tense and narration format; omit them to drop that guidance. **Reset to defaults** restores the stock templates.
- **More tag categories** — **Dynamic** and **Kink & Fetish** join Identity, Personality, Role, Genre, Tone, and Appearance. Hide any category, or **Hide NSFW tags** to drop Kink & Fetish from the browser, search, and Feeling Lucky. Hidden categories stay out of Lucky; tags you already picked still generate.
- **Favorites, recents, custom tags** — Star tags you reuse. Recents sit at the top of the picker. Add your own tags per category (not Generation). Custom tags persist in settings; a slug that already exists in another category is rejected.
- **Go Back** stays on screen while a run is live and after it finishes. It stops generation, clears the preview, and returns you to the same concept or tags.

[AI Creation Studio →](/features/ai-creation-studio)

### Agent review

By default the Agent still writes when the run finishes. Turn on **Settings → Character Workspace → Review agent edits before applying** and those writes **stage** instead.

- A **Review agent edits** modal lists each field, greeting, and lorebook change with a word-level **Original / Agent** diff and `+added` / `−removed` counts.
- Approve or deny per change, or **Approve all** / **Deny all**. Expand a change to edit the proposed text (and lorebook keys) before it lands.
- Close the modal to decide later. A yellow **Review (N)** chip in the chat header brings it back. Send stays blocked until you apply or discard.
- **Apply** takes one snapshot first, same as auto-apply. Edits you made in the editor to fields the Agent did not touch are kept.

Off is the 1.4.x behavior. Character Agent and lorebook Agent share the same toggle.

[AI Agent → Review edits](/features/ai-agent#review-edits)

### Also in this release

- **Settings split** — the old Studio tab is now **Character Workspace** (default chat, Agent review, editor links, spellcheck) and **Creation Studio** (fields, tags, prompts, lucky vortex). Open Settings from a character, a lorebook, the vault header, or the studio.
- **Vault library** — page numbers at the **top and bottom** of the character grid, plus a **More** menu and Settings on the vault header.
- **Appearance** (`physical_description`) round-trips on PNG/JSON import and export for V2 and V3 cards.
- Recursion map layout is tighter on phones (safe-area padding).

## Fixes

- Studio generation no longer keeps orphaned AI streams after a settings reload, and skips fields you disabled mid-run.
- Custom-tag writes cannot race each other; Feeling Lucky ignores hidden categories.
- Deleting a character also drops its stored image, settings pointer, and pending writes.
- Agent composer stays locked while a review is pending, so a second run cannot stack on unapplied writes.

## Upgrade

Client-only app. Open the hosted site or rebuild locally; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Local data from 1.4.5 keeps working. Studio prompts, field toggles, and tag prefs save on the existing settings record. Agent review is off until you enable it.

Hard refresh if the UI looks stale after deploy.
