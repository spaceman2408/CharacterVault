# CharacterVault 1.4.1

A patch on 1.4.0: smoother Agent chat, a first-run tutorial that matches the current product, and a staging preview banner on the production vault.

**Try it:** https://vault.charactervault.app  
**Staging:** https://staging.charactervault.app  
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Agent chat

- **Composer stays focused** while a run is in progress. The textarea is no longer disabled, so the browser does not steal focus. Focus returns after Send and Stop.
- **Agent writing** moved from an editor banner into a pulsing label in the workspace header (character and lorebook).
- **Live speech** streams into the Agent thread after thinking, throttled the same way as thinking. Tool XML is stripped from the live draft, and the in-stream buffer is capped.
- **Error bubbles** on a user message clear when you Send or regenerate. They no longer stick around after a retry.
- **Native tools vs XML** is one control plane per prompt. If the provider returns 400 on `tools`, CharacterVault remembers that model, rebuilds an XML-only system prompt, and retries the turn. Later runs for that model start in XML and skip native tools.

[AI Agent →](/features/ai-agent)

### First-run tutorial

The welcome overlay is a 7-step orientation instead of the old 6-slide list:

- Vault (Characters and Lorebooks, Import, New, AI Create, Backup)
- Tabbed editor
- Toolbar, Orion, and Agent
- Lorebook vault and linking
- Snapshots, export, and backup

People who already finished the old tutorial are not prompted again. Replay from the help icon (**?**) in the vault header.

### Staging preview

On the production vault, a dismissible header strip points at [staging.charactervault.app](https://staging.charactervault.app) so you can try upcoming features before they ship. It is hidden on the staging host itself. The SillyTavern extension card sits a bit lower so it clears the bar.

## Upgrade

Client-only app. Open the hosted site or rebuild locally; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Local data from 1.4.0 keeps working. Hard refresh if the UI looks stale after deploy.
