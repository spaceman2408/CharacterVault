# CharacterVault 1.10.0

CharacterVault 1.10.0 adds Find & Replace across a whole character or lorebook, with a grouped preview, a snapshot before every replace, and Undo. The AI Creation Studio shows each field's thinking while it writes and works with endpoints that need no API key, plus fixes for editing, Stop, and Regenerate during generation and for V3 card fields lost on import.

**Try it:** https://vault.charactervault.app
**Staging:** https://staging.charactervault.app
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Find & Replace across a character

**Character header → Find** (search icon), or **Ctrl+Shift+F** (**Cmd+Shift+F** on Mac) from anywhere in a character. Select a word first and it lands in **Find**. It searches every text field, each greeting, and the character's lorebook entries (title, name, keys, filter keys, content). **Ctrl+F** still opens the small find bar in the editor.

- **Grouped preview** — matches are grouped by place, with the old text struck through next to the new. Untick a match or a whole group, and click a match to open that section. Up to 2,000 matches are listed.
- **Options** — **Aa** (match case), **ab** (whole word), **.*** (regular expression), and **AB** (preserve case) next to **Replace**.
- **Replace or Remove** — **Replace** changes the ticked matches in one step, and the button shows how many. With the **Replace** box empty, it becomes **Remove**.
- **Undo** — a toast offers **Undo**, which puts the card back unless you edited it since. **Snapshots** keeps a **Find & Replace save point** from just before.

[Text Editor → Find & Replace](/features/editor#find-replace)

### Find & Replace in lorebooks

**Lorebooks → open a book → Find**, or **Ctrl+Shift+F**. It searches the book name, the book description, and every entry's title, name, keys, filter keys, and content. Replace, Undo, and Snapshots work the same as in a character. Replacing text in the book name renames the lorebook; emptying the name is refused.

[Lorebook Vault → Find & Replace](/features/lorebook-vault#find-replace)

### Creation Studio thinking and keyless endpoints

With a thinking model, each field in the **AI Creation Studio** shows an open **Thinking** block while it generates, like Orion, and folds it once the field is done. Raise **Reasoning effort** if the model skips thinking.

- **No API key needed** — a custom URL on any hostname with an empty key now works in the Studio, and **Settings → Prompts → Model for this prompt** fetches its models. An endpoint that does need a key returns its own error.

[AI Creation Studio → Generation Process](/features/ai-creation-studio#generation-process)

### Also in this release

- **Save to Vault** stays hidden while a character is generating, including Retry and Regenerate. Press **Stop** first to save a partial card.

## Fixes

- **Studio edits during generation**: editing a finished field while the rest is generating keeps your edit, and later fields use it.
- **Studio Regenerate**: a stopped or failed Regenerate puts the old text back.
- **Studio input modes**: a concept typed in **Write** stays after switching to **Tags** and back.
- **Studio Stop**: shows **Partially Complete** with **Continue** instead of **Generation Failed**.
- **V3 card fields**: nickname, group-only greetings, source, assets, multilingual creator notes, and creation and modification dates now survive import and export.

## Upgrade

Client-only app. Open the hosted site, rebuild locally, or rebuild the Docker image; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Running it with Docker? Pull and rebuild the image:

```bash
git pull
docker compose up -d --build
```

Local data from 1.9.2 keeps working. Cards keep their V3-only fields from now on; import a card again to recover fields an earlier import dropped. Hard refresh if the UI looks stale after deploy.
