# CharacterVault 1.8.2

CharacterVault 1.8.2 makes inline AI results easy to retry, time, and reuse, speeds up search, font size, image links, and name macros in the editor, and carries card lorebook options and JPEG or WebP images cleanly to SillyTavern, plus a bigger spellcheck dictionary and a round of editor fixes.

**Try it:** https://vault.charactervault.app
**Staging:** https://staging.charactervault.app
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Inline AI results you can retry and reuse

Select text, run a toolbar action, and the result strip now does more than Accept and Reject.

- **Retry** — **↻ Retry** on the result strip and on the error strip runs the same request again.
- **Reject reopens Custom** — rejecting a Custom result puts your instruction back in the Custom box so you can tweak it.
- **Model and timing** — the result header shows pills for the model, time to first token, and speed (t/s). A **⚠ Cut off at Max Tokens** warning appears when the reply hit the limit.
- **Rewrite or Insert** — the Custom button reads **Rewrite** with a selection and **Insert** without one (writes at the cursor). **Esc** and **Cancel** keep what you typed.
- **Recent instructions** — in an empty Custom box, **↑** steps back through your last 10 instructions. The clock button lists them, with **✕** to remove one and **Clear all** (click twice).

[Editor → Ghost Preview](/features/editor#ai-operation-results-ghost-preview)

### Faster editing

- **Search** — `Ctrl+F` finds, `Ctrl+H` (`⌘+Alt+F` on Mac) opens Replace, `F3` or `Ctrl+G` steps through matches, and **Enter** in the Replace box replaces the current match. The count matches the highlights, and the query stays after **Replace All**.
- **Font size** — the **aA** slider resizes text live while you drag (6–32px, default 16). `Ctrl/⌘ + =` and `Ctrl/⌘ + -` step it, `Ctrl/⌘ + 0` resets, and the standalone lorebook remembers its size.
- **Image links** — `Ctrl+click` (`⌘+click` on Mac) or a tap on `![](https://…)` opens the image after a **Leaving CharacterVault** warning; a plain click just places the cursor to edit the URL. URLs with parentheses stay whole.
- **Name macros** — typing `char` or `user` turns into `{{char}}` / `{{user}}` when you finish the word. **Backspace** right after keeps the plain word. On by default; turn it off in **Settings → Character Workspace → Name macros**.

[Editor → Search & Replace](/features/editor#search-replace)

### Clean round-trips to SillyTavern

- **Card lorebook options** — recursion flags, probability, depth, role, keyword logic, whole-word matching, insertion order, and position on a card's own lorebook now import from and export to the places SillyTavern reads them. **Insertion Order** in the entry options is the order SillyTavern uses.
- **Older cards catch up** — cards and library lorebooks saved before this release pick up their SillyTavern options when opened. A position you changed in CharacterVault is kept.
- **PNG export from any image** — **Export → PNG** converts JPEG, WebP, and other images to PNG instead of failing, and vault backups keep those cards as PNG with their image.

[Import & Export → PNG](/features/import-export#png)

### Also in this release

- **Spellcheck** uses a bigger dictionary and checks in the background, so fewer real words are flagged and long fields type smoothly.
- **AI Creation Studio** asks before **Go Back** or the back arrow discards a card you haven't saved.
- **Japanese / Chinese / Korean input** — **Enter** and **Esc** while composing no longer send or close things.
- **Docs refresh** — an AI setup quick start, a section on local backends (LM Studio, KoboldCpp, Ollama) and CORS, an overview of which AI feature does what, and privacy notes on the NanoGPT usage check and Creator Notes remote content.

## Fixes

- **Editor highlighting** — *actions* after **bold** on the same line highlight again, and a height like 6'2" no longer turns the rest of the line into dialogue.
- **Name macros** convert as you type, with no crash on **Enter** or paste.
- **Inline AI** — an empty AI reply shows an error instead of locking the editor. **Esc** in a dialog or the font-size popup no longer rejects the result.
- **Search** prefills only short selections, keeps the replace text, and **Esc** closes search from anywhere in the panel.
- **Spellcheck** no longer flags numbers like 6'2 or 1-2.
- **Snapshots** — pinning a lorebook entry for AI context no longer shows as a change.
- The Agent's review shield tooltip points to **Settings → Character Workspace**.

## Upgrade

Client-only app. Open the hosted site or rebuild locally; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Local data from 1.8.1 keeps working. Card lorebooks saved earlier are updated to the new option layout the next time you edit that card or book. Hard refresh if the UI looks stale after deploy.
