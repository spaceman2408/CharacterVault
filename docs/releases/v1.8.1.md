# CharacterVault 1.8.1

CharacterVault 1.8.1 brings snapshot diffs laid out like the Agent review, a one-click Orion / Agent switch with edit-and-resend in Orion, and a Creator Notes preview that can't quietly phone home, plus a large round of fixes to saving, import, export, and the lorebook editor.

**Try it:** https://vault.charactervault.app
**Staging:** https://staging.charactervault.app
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Snapshot diffs like the Agent review

Click **Snapshots** in the workspace header and pick a revision. Each change is now a card, the same as in the Agent review.

- **Side by side or inline** — wide screens show **Revision** and **Current** next to each other; phones get one column. Only the words that changed are highlighted, long unchanged stretches fold behind **Show N unchanged lines**, and each card header counts words added and removed.
- **Restore per card** — each field card has its own **Restore**. Greetings and the lorebook restore as a whole from the **Restore** next to their heading.
- **Greetings and lorebook cards** — one card per greeting added, deleted, or edited, so deleting greeting 2 of 5 reads as one deletion. One card per lorebook entry, with its keys, content, and any changed flags or settings; book name, scan settings, and entry order get a **Book settings** card.
- **No more empty diffs** — a missing field and an empty one count as the same, and so do Windows and Unix line endings. The amber dot in the timeline uses the same check, so a dot always has something to show. Spacing-only edits say so.

[Snapshots → Diff Viewer](/features/snapshots-history#diff-viewer)

### Orion and the Agent share one chat header

- **Mode switch** — at the left of the chat header, the chat bubble is Orion and the robot is the Agent. The highlighted icon is the one in use, and the other is one click away. Same switch on characters and standalone lorebooks.
- **Edit and resend in Orion** — the pencil on your last message puts its text back in the box. Nothing is removed until you send; then that message and the replies after it are replaced. The **×** cancels and keeps the chat as it was.
- **Your message stays put** — if Orion can't send yet (the chat is still loading, or AI isn't set up), the text goes back in the box instead of disappearing.

[AI Assistant → Editing your last message](/features/ai-assistant#editing-your-last-message)

### Remote content in Creator Notes and chat

- **Preview lockdown** — the Creator Notes preview loads only https images, fonts, and stylesheets, plus images embedded in the notes. Everything else is blocked, and scripts never run.
- **Tracking warning** — when the notes pull images, fonts, or styles from another site, the preview says so: that site can see your IP address and that you opened the card. On by default; turn it off in **Settings → Character Workspace → Warn about remote content in Creator Notes preview**. The setting is kept in settings backups and vault restores.
- **Images in chat are links** — images in Orion and Agent replies show as **Image: …** links that open on click, so a reply can't load a URL on its own.

[Creator Notes → Sandboxed Rendering](/features/creator-notes#sandboxed-rendering)

### Also in this release

- **Card tokens in the header** — the workspace header shows the whole card's active and total token estimate next to the save status, the same numbers as the library card. Hover for exact counts. Shown on wider screens.
- **Greetings list** — every greeting shows its token count, and the list header shows the total. **Tab** and **Enter** select a greeting, and phones now show which greeting is open.
- **Greetings keep your place** — switching sections and coming back keeps the greeting you had open. Clicking a greeting line in the Agent chat opens that greeting.
- **Card image by drop or paste** — on the Image tab, drop an image or paste one from the clipboard. With no image yet, clicking the empty area opens the file picker. Replacing an existing image asks first.
- **Lorebook entry tokens** — every entry row shows the token count of its content, not only the selected entry.
- **Retry in Orion** — when a reply fails, the error banner has **Retry**, and **Enter** in the empty message box retries too. **Esc** in the message box stops a running reply, in Orion and the Agent.
- **Inline AI keeps your selection** — after **Reject**, **Stop**, or closing an error, the text you had selected is selected again, ready for another action.
- **Reset one prompt** — in **Settings → Prompts** and **Creation Studio**, a prompt you changed shows **edited** and a **Reset to default** link. It asks before resetting, and so does the Studio's **Reset to defaults** for all prompts.
- **Agent key test** — ask the Agent to test a line a user might write. It lists the lorebook entries that would activate and the key that matched, plus key hits that stay off, and follows recursion when recursive scanning is on. Read-only.
- **Agent audit** checks example dialogue for a `<START>` line and a `{{char}}:` line in each block.
- **Remove Image** is now a labelled button next to **Change Image** on the Image tab, and asks before removing. The old trash icon only appeared on hover and could be hit by a stray tap on touch screens.
- **Settings → AI Config** shows why models failed to load (bad key, unreachable URL) under the model picker, until a fetch succeeds.
- **Vault feedback** — a failed delete or copy shows an error and keeps the dialog open, and a quick double click no longer makes two copies. Dropping a backup ZIP along with other files says the others were skipped; dropping files while an import runs says to drop them again.
- **Paste from Clipboard** on the import page says when the clipboard is empty or can't be read, and puts the cursor in the paste box.
- **AI Creation Studio** shows an error when **Save to Vault** fails; the generated card stays on screen so you can try again.
- **Stalled replies** — a reply that sends nothing for 3 minutes stops with a retryable error instead of hanging until you press Stop. Replies over 32 MB are cut off.
- **Faster big lorebooks** — editing an entry re-renders only that row, and review and snapshot cards build their line diffs only while open.

## Fixes

- **Saving**
  - The header no longer says **Saved** while another field is still saving, or after a field failed to save.
  - Edits typed while a save is being written are no longer dropped, and the status no longer sticks on **Saving…**.
  - **Export → PNG / JSON** from the workspace saves pending edits first, including an open lorebook entry, so the file has your latest text.
- **Greetings** — Undo after switching greetings, or after deleting the one on screen, no longer writes the previous greeting's text into the current one.
- **Lorebook**
  - Exports for SillyTavern key each entry by its UID. After deleting entries, SillyTavern could edit the wrong entry. Entries with a duplicate or missing ID get a free UID instead of being lost.
  - **Probability**, **Insertion Order**, and **Depth** keep what you type. Clearing Probability no longer snaps to 100 (typing 50 gave 1005), and negative orders can be typed. Leaving a field empty sets 100, 0, and 0; out-of-range values are clamped.
  - After the Agent jumps to an entry, going back to the Lorebook tab no longer reselects it every time.
  - The context eye is green only for entries that are enabled and in context. Disabled entries are never sent to AI context.
  - Untitled entries show as **Entry #ID** in the list, the title placeholder, and the recursion map alike.
  - The standalone lorebook header's token total counts keys and titles, matching the AI context meter.
- **Import**
  - PNG cards that only carry a V3 `ccv3` chunk import; when both chunks are present, `ccv3` wins, like SillyTavern. Compressed `iTXt` chunks import too, up to 64 MB unpacked.
  - Importing or duplicating a card no longer marks it as opened, so **Recent** and the **Continue** pill stay on cards you actually opened.
- **Escape** in a confirm dialog closes only the dialog. Inside Settings it used to close Settings too and lose unsaved changes.
- A file dropped where nothing accepts it no longer opens in place of the app. Dropping a text file into an editor still inserts its text.
- The **Greetings** tab has its own icon instead of the Description icon.
- Picking the same avatar file again after removing it works.
- Custom toolbar buttons from an imported settings backup show their icon and label as plain text.
- Creating a card no longer reports a failure when the card saved but its "last opened" time didn't.
- Rejected-request bodies in the browser console are trimmed to 500 characters, since some gateways echo the prompt back.
- Screen-reader labels for the notification close button and the toolbar search button.

## Upgrade

Client-only app. Open the hosted site or rebuild locally; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Local data from 1.8.0 keeps working. The Creator Notes warning is a new setting that starts on. Hard refresh if the UI looks stale after deploy.
