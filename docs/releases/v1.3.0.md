# CharacterVault 1.3.0

Standalone **Lorebook Vault**, fuller SillyTavern World Info editing, and a **recursion map** for unlock paths and bulk recursion flags.

**Try it:** https://spaceman2408.github.io/CharacterVault  
**Docs:** https://spaceman2408.github.io/CharacterVault/docs/

---

## Highlights

### Lorebook Vault

- Second home-vault library: **Characters** | **Lorebooks**
- Create, search, import, export, duplicate, and delete standalone books
- Full workspace: shared entry editor, Orion chat, history/snapshots
- Local IndexedDB only (same privacy model as character cards)

[Lorebook Vault →](/features/lorebook-vault)

### Attach and embed

- **Attach** vault books to a character for vault-local AI context (not on the card export by itself)
- **Copy into embedded lorebook** when you want entries on the V2/V3 card for SillyTavern

### Lorebook editor (shared)

- Character tab and vault books share one editor
- Common ST fields: selective logic, recursion flags, probability, depth/role, match whole words, book scan depth / token budget / recursive scanning
- AI context usage bar and per-entry eye toggles (Character Vault AI only)
- Field help icons aligned with [SillyTavern World Info](https://docs.sillytavern.app/usage/core-concepts/worldinfo/)

[Lorebook Editor →](/features/lorebook-editor)

### Recursion map

- **This entry**: who unlocks this / what this unlocks
- **Whole book**: search, filter, inspect paths, select all / visible / linked
- Bulk set Non-recursable, Prevent further recursion, Delay until recursion; **Isolate** both directions
- Authoring aid based on primary keys in content (not a full ST runtime sim)

[Recursion map →](/features/lorebook-editor#recursion-map)

### Snapshots

Standalone books support open / auto / manual / rollback snapshots from the lorebook workspace History modal.

[Snapshots →](/features/snapshots-history#standalone-lorebook-snapshots)

## Upgrade

Client-only app. Open the hosted site or rebuild locally.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Existing character data and settings continue to work. IndexedDB gains lorebook tables on first open of a build that includes this feature (schema migration). Export lorebook JSON if you want portable copies outside the browser.

Hard refresh if the UI looks stale after deploy.
