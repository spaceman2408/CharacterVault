# CharacterVault 1.3.0

Standalone **Lorebook Vault**, fuller SillyTavern World Info editing, and a **fullscreen recursion map** with a visual web of unlock paths and safe bulk flag edits.

**Try it:** https://spaceman2408.github.io/CharacterVault  
**Docs:** https://spaceman2408.github.io/CharacterVault/docs/

---

## Highlights

### Lorebook Vault

- Second home-vault library: **Characters** | **Lorebooks**
- Create, search, import, export, duplicate, and delete standalone books
- Import names the book from the **filename** (including Windows copy suffixes like `(1)`), not the shorter name inside the JSON
- SillyTavern book scan settings (`scan_depth`, `token_budget`, `recursive_scanning`) survive import and are written back on export
- Full workspace: shared entry editor, Orion chat, history/snapshots
- Local IndexedDB only (same privacy model as character cards)

[Lorebook Vault →](/features/lorebook-vault)

### Linking and sync

- A character can **link one** library book; several characters can share the same book
- Linking asks if you want to copy that book onto the character (replaces the lorebook already on the card)
- **Open in vault** writes the character’s current lorebook to the library book, then opens it
- Edits in the Lorebooks workspace update **every linked character**
- Exporting a card includes the lorebook **on that character**, not the link itself
- **Detach** if you do not want a character to keep following the library book

[Linking →](/features/lorebook-vault#attach-to-a-character-vault-local)

### Lorebook editor (shared)

- Character tab and vault books share one editor
- **Content-first**: title, keys, Enabled / Constant, and the content editor stay on screen
- **Options** and **Attach** are header buttons that open a panel over the editor (**Done** or **Escape** to close)
- On a phone, the entry list and the editor swap; **Attach** is also next to book settings on the list
- Common ST fields: selective logic, recursion flags, probability, depth/role, match whole words, book scan depth / token budget / recursive scanning
- AI context usage bar and per-entry eye toggles (Character Vault AI only)
- Bring books in through the **Lorebooks** vault, then **Attach** — the editor no longer replaces the current book from a JSON file. **Export** is unchanged
- Field help icons aligned with [SillyTavern World Info](https://docs.sillytavern.app/usage/core-concepts/worldinfo/)

[Lorebook Editor →](/features/lorebook-editor)

### Recursion map

- **Visual web view**: the whole book as a node graph - arrows show which entries can unlock which, clustered by chain
- **Pan, zoom, and hover spotlight**; click to inspect (pins those paths), hover another node to temporarily override, click again or the inspector **X** to clear. Ctrl-click to select
- **Edit primary keys on the map**: inspector and hop-row chips write to the real entry and rebuild the arrows immediately
- **List view** with search and All / Linked / Standalone filters; automatic fallback for large books
- **Per-entry flag toggles** right in the inspector (apply immediately)
- **Staged bulk edits**: pick a flag change, review what is staged and for how many entries, then Apply or Discard - nothing changes silently
- Camera stays put when you inspect or when arrows change; dense books wrap tall ranks and pan/zoom without redrawing every edge
- Authoring aid based on primary keys in content (not a full ST runtime sim). The map only warns about recursive scanning when this book explicitly turns it off

[Recursion map →](/features/lorebook-editor#recursion-map) · [Guide →](/features/recursion-map-guide)

### Snapshots

Standalone books have their own History modal. The **Opened** snapshot is the baseline (you can update it in place, but you cannot delete it). Save a snapshot when something actually changed; restoring a book also updates linked characters.

[Snapshots →](/features/snapshots-history#standalone-lorebook-snapshots)

## Upgrade

Client-only app. Open the hosted site or rebuild locally.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Existing character data and settings continue to work. IndexedDB gains lorebook tables on first open of a build that includes this feature (schema migration). Export lorebook JSON if you want portable copies outside the browser.

Hard refresh if the UI looks stale after deploy.
