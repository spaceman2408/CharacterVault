# CharacterVault 1.7.5

This release makes **agent-review greeting changes easier to read** (new and removed greetings are labeled, and list edits show per-greeting blocks), lets **custom tags join the Creation Studio's gender rules** for Feeling Lucky and tag gray-outs, and steadies thinking and chat autoscroll.

**Try it:** https://vault.charactervault.app
**Staging:** https://staging.charactervault.app
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Review agent greeting changes

When you run the Agent with **Review edits** on, greeting changes now read at a glance instead of as one undifferentiated blob.

- **New alternate greeting** — an added greeting is labeled **New alternate greeting** on a **Greeting #N** row, with an empty **Original** beside it.
- **Removed greeting** — a deleted greeting is labeled **Deleted alternate greeting** and shows on the Original side with an empty Agent side.
- **Greetings list** — a rewrite of the whole list shows per-greeting blocks on both sides, a `+N greeting(s)` / `−N greeting(s)` count badge, and **New** / **Removed** badges on the affected blocks.
- **Aligned text diffs** — long-text changes align paragraph by paragraph and line by line, keeping kept lines plain and highlighting only the reworded fragments when a change is small.

When you edit a **Greetings list** change, separate greetings with a line containing only `---`.

[AI Agent → Review edits](/features/ai-agent#review-edits)

### Custom tags join Studio gender rules

AI Creation Studio now treats your custom tags as first-class during tag selection.

- **Feeling Lucky draws custom tags** — a lucky draw uses the merged built-in plus custom pools, so custom tags can be picked instead of only built-ins.
- **Custom tags gray out by gender** — a selected female- or male-coded tag grays out the opposite-gender tags on the grid, and your custom tags are classified the same way built-ins are.
- **Mixed scenarios stay selectable** — tags carrying both sides (e.g. `futanari`, `father-daughter`), and unrecognized tags, stay neutral so they are never over-blocked.

[AI Creation Studio → Feeling Lucky](/features/ai-creation-studio#feeling-lucky) · [Tags Mode](/features/ai-creation-studio#tags-mode)

### Also in this release

- The Agent rejects an empty greeting add or update with an error instead of saving a blank greeting.
- The review modal re-syncs its decisions and expanded row when a new review payload arrives while it is open.

## Fixes

- Thinking and chat streams now follow the bottom reliably during fast token bursts and release cleanly when you scroll up, using position-based stickiness and coalesced scroll pins.

## Upgrade

Client-only app. Open the hosted site or rebuild locally; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Local data from 1.7.0 keeps working. Hard refresh if the UI looks stale after deploy.
