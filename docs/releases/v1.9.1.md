# CharacterVault 1.9.1

CharacterVault 1.9.1 gives the Agent skills: named instructions it loads when your request matches, with three that ship and your own in a new **Agent Skills** settings tab. Settings now save automatically, saved presets show up in the Prompts tab model pickers, and the Agent chat highlights @mentions, plus a fix for settings changes not reaching the lorebook Agent until a reload.

**Try it:** https://vault.charactervault.app
**Staging:** https://staging.charactervault.app
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Agent skills

A skill is a set of instructions for one kind of task. The Agent sees each skill's name and **when to use** line, loads the full instructions when your request matches, and its reply shows **Used skill “Name”**. Type `@` in the Agent chat to pick one yourself, for example `@Cut AI Slop`.

- **Three that ship**: **Greeting Writer** for the first message and alternate greetings, **Lorebook Entries** for new entries and their keys, and **Cut AI Slop** for tightening prose.
- **Your own**: **Settings → Agent Skills → New** adds a skill with a name, a when-to-use line, and instructions. An edited default gets **Reset to default**, and a deleted one can be added back.
- **On and off**: each skill has its own switch, and **Use skills** at the top turns them all off without losing any.
- **Agent tools glossary**: a list under the skills names every tool the Agent can call, with a one-line summary and a **Card only** or **Lorebook only** tag. Click a name to copy it into a skill's instructions.
- **Shared and backed up**: both Agents use the same skills, and settings backups include them.

[AI Agent → Skills](/features/ai-agent#skills)

### Settings save automatically

There is no **Save Settings** button now. A change saves a moment after you make it, and prompt text saves when you click out of the box. The footer shows **Saving…**, **Saved**, or **Not saved** with the reason, for example a prompt missing `${text}`.

- **Close anytime**: **Close** or **Escape** saves anything still waiting, so the discard-changes dialog is gone.
- **Undo**: **Reset to default** and variable chips on the Prompts tab can be undone with **Ctrl+Z** (**⌘+Z**).
- **Backup import asks first**: importing a settings backup asks **Restore settings from backup?** before replacing anything.

[AI Setup → Opening Settings](/configuration/ai-setup#opening-settings)

### Saved presets in model routing

Every endpoint picker on **Settings → Prompts**, including the **Agent** and custom toolbar buttons, lists your saved presets by name under **Saved**. Picking one sets both its endpoint and its model. Picking a plain provider stays on it, even when its remembered model is also a preset.

[AI Setup → Per-prompt model routing](/configuration/ai-setup#per-prompt-model-routing)

### Also in this release

- **@mention highlights**: in the Agent chat box, @mentions that match a skill, field, greeting, or lorebook entry are tinted as you type, so you can see they will resolve.

## Fixes

- **Settings reaching the lorebook Agent**: a change saved from a character, the library, or Creation Studio, such as a new API key or a skill edit, now reaches the lorebook Agent without reloading the page, instead of it asking you to configure AI settings first.

## Upgrade

Client-only app. Open the hosted site, rebuild locally, or rebuild the Docker image; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Running it with Docker? Pull and rebuild the image:

```bash
git pull
docker compose up -d --build
```

Local data from 1.9.0 keeps working. The default skills appear on first load, and settings saved before 1.9.1 read with skills on. Hard refresh if the UI looks stale after deploy.
