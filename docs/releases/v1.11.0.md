# CharacterVault 1.11.0

CharacterVault 1.11.0 reworks the AI Creation Studio with shorter prompts, a note on Regenerate, and a default perspective and tense, lets the Agent pick place names and share skills as files, and adds favorite characters and a check for common mistakes before export, plus a minimum quantization filter for OpenRouter.

**Try it:** https://vault.charactervault.app
**Staging:** https://staging.charactervault.app
**Docs:** https://vault.charactervault.app/docs/

---

## Highlights

### Creation Studio rework

The **AI Creation Studio** writes with new, shorter default prompts: the description gets a **Speech** section, the first message and examples never act or speak for `{{user}}`, and examples say `{{char}}` instead of the name. Studio prompts you edited in **Settings → Creation Studio** are kept; untouched ones update on their own.

- **Regenerate with a note** — once a field is done, the note button next to **Regenerate** takes a short change like *make them older* and rewrites just that field.
- **Description changed** — edit or regenerate the Description and **First Message** and **Examples** say so until you regenerate them.
- **Default style** — click the star inside a perspective or tense chip and it is preselected when you open the Studio and after **Create Another**. One default per row.
- **Tags** — the concept groups tags by category (`Identity: …; Tone: …`). Every chip works the same: click the name to select, the star to favorite. **Generation Style** is a collapsible section above Identity, and your own tags delete with the trash icon inside the chip (two clicks).
- **AI not configured** — with no provider set up, a button in the header replaces the big warning box.

[AI Creation Studio → Preview & Editing](/features/ai-creation-studio#regenerate-with-a-note)

### Agent place names and skill files

Ask either Agent for a new town, region, river, mountain, lake, or inn, or to rename a placeholder like *Oakhaven*. It calls `suggest_places` and picks from the list: invented names for fantasy worlds, real towns for real-world settings, and never a place already named on the card or in its lorebook.

- **Skill files** — **Settings → Agent Skills → Import / Export all / Select** exports one skill, several, or all to a `.json` file. Import also takes Markdown skill files (`SKILL.md` with `name` and `description` frontmatter), several at once. A name that already exists asks **Replace** (updates it in place, keeps it on or off) or **Keep both** (adds a numbered copy).
- **Shorter tool descriptions** — every Agent request sends less context.

[AI Agent → Place names](/features/ai-agent#place-names) · [AI Agent → Skill files](/features/ai-agent#skill-files)

### Favorites and export check

- **Favorites** — the star on a library card pins that character to the top of the grid in every sort.
- **Check before export** — exporting a card first lists likely mistakes: an empty name or first message, blank greetings, broken or misspelled `{{char}}` / `{{user}}` macros, leftover AI tags like `<think>`, examples with no `<START>` line, and lorebook entries with no keys. **Go to** jumps to the field in the editor, **Open card** opens it from the library, and **Export anyway** downloads it as is. On by default; turn it off in **Settings → Character Workspace → Export → Check cards before export**.

[Vault Organization → Favorites](/features/vault-organization#favorites) · [Import & Export → Check before export](/features/import-export#check-before-export)

### OpenRouter minimum quantization

**Settings → AI Config → Provider** on OpenRouter adds **Minimum quantization** (Any by default), which skips hosts below the chosen precision, and **Hide unknown** (off by default), which also skips hosts that do not report one. Skipped hosts show greyed out in the Provider list.

[AI Setup → Minimum quantization](/configuration/ai-setup#minimum-quantization)

## Upgrade

Client-only app. Open the hosted site, rebuild locally, or rebuild the Docker image; no server migration.

```bash
git clone https://github.com/spaceman2408/CharacterVault
cd CharacterVault
npm install
npm run dev
```

Running it with Docker? Pull and rebuild the image:

```bash
git pull
docker compose up -d --build
```

Local data from 1.10.0 keeps working. Favorites are saved on each character in this browser; a vault backup does not carry them. Hard refresh if the UI looks stale after deploy.
