Card Editor

Every V2 and V3 field in a real text editor.

Each text section opens in CodeMirror 6 with syntax coloring for roleplay formatting, offline spellcheck, live token estimates, and card-wide search.

V2 & V3 Spec

All your card fields in one workspace.

Import a PNG or JSON card to edit Name, Description, Personality, Scenario, First Message, Alternate Greetings, Example Dialogue, System Prompt, Post-History, Creator Notes, Tags, and Extensions. V3 fields survive import and export.

  • Color-coded "dialogue", *actions*, and {{char}} / {{user}} macros
  • Bundled offline Hunspell spellcheck that skips macros, code blocks, and URLs
  • Card-wide Find & Replace (Ctrl+Shift+F) with grouped preview and Undo
  • Preserves cursor position, scroll state, and undo history across tabs

Creator Notes with SillyTavern preview

Write Markdown, HTML, and scoped CSS with a resizable split Dock preview. Turn on Match SillyTavern to test panel widths, dark/light/checkerboard backgrounds, starter snippets, color swatches, and CSS formatting. Scripts never run, and remote media shows a privacy notice.

Snapshots and word-level diffs

Keep up to 10 snapshots per character, including a protected baseline when you first open a card and automatic save points before Agent edits or Find & Replace. Compare changes side by side and restore the entire card or one section.

Library search and sorting

Browse cards in a responsive portrait grid with active and total token estimates. Press / to search by name or tags, click tag chips to filter, sort by Name, Recent, or Created, and return to your last card with the Continue pill.

SillyTavern Companion

Send cards straight from SillyTavern.

Drag and drop PNG or JSON files onto your vault, or install the SillyTavern companion extension. It adds Export to CharacterVault to SillyTavern's export menu so one click opens the import preview with the character portrait included.

World Info & Lorebooks

Map how your lore connects and share books across cards.

Edit embedded character lorebooks or keep standalone World Info books in the Lorebook Vault. Link a shared book to multiple characters so updates stay in sync, and inspect unlock paths in the recursion map.

Lorebook editor docs → Recursion map guide →

Standalone Lorebook Vault

Manage World Info books independently with search, snapshots, Find & Replace, and JSON import/export. Link one book to multiple characters at once. Exporting a card still embeds the full lorebook automatically.

Full SillyTavern World Info fields

Edit primary and secondary keys, /regex/ patterns, selective logic (AND ANY, NOT ALL, NOT ANY, AND ALL), insertion order, position, depth, role, probability, and recursion flags. Unedited SillyTavern fields survive standalone JSON round-trips.

Interactive Recursion Map

See every path where one entry's prose mentions another entry's primary keys. Spot blocked links or entries that can never activate, edit keys as chips directly on the map, and toggle recursion flags in bulk.

Local-First Storage

Stored in your browser, under your control.

Your characters, portraits, lorebooks, snapshots, and API keys stay in local browser storage and are never uploaded to a CharacterVault server.

IndexedDB on your device

No account, no cloud library, and no ad trackers. Once the app loads, editing, lorebooks, and PNG/JSON export keep working even if your connection drops.

One-file ZIP backups

Click Backup to export every character (embedded PNG or JSON), standalone lorebook, and your settings into one ZIP. API keys stay excluded unless you explicitly opt in.

Direct-to-provider AI traffic

Optional AI requests go straight from your browser to the provider or local server you configure. The one exception is the NanoGPT subscription-usage check, which uses a small no-log Cloudflare proxy because NanoGPT blocks that call in browsers. Read Privacy Notice.

Self-Hosting

Run your own copy locally.

Want full offline access? Start it locally with Docker Compose or Node. Your data stays in your browser for that address, and stopping or rebuilding the container loses nothing.

FAQ

Frequently asked questions.

Need more details? Check the full FAQ in the docs or ask in Discord.

Is CharacterVault completely free?

Yes. Every feature is free with no account, trial limit, or paid tier. CharacterVault is open source under the GPL-3.0 license.

Do I need an AI API key or subscription?

No. The card editor, lorebooks, recursion map, Creator Notes preview, snapshots, and import/export all work without AI. When you do want AI tools, connect any OpenAI-compatible provider or a local server like LM Studio, Ollama, or KoboldCpp.

Where are my cards and API keys stored?

Locally in your browser's IndexedDB and site storage on your device. CharacterVault has no user database and never uploads your cards. AI requests go directly from your browser to the provider you configure.

Are my existing SillyTavern cards and World Info books supported?

Yes. Drag and drop PNG cards with embedded metadata (chara or ccv3), V2/V3 JSON cards, or standalone World Info lorebook JSON. Export back to PNG or JSON anytime, or send cards straight from SillyTavern with the companion export extension.

What happens if I clear my browser data?

Because your vault lives in browser storage, clearing site data removes your local cards, lorebooks, snapshots, and settings. Use Backup in the library header periodically to download a portable ZIP backup you can import in any browser.

Does it work on mobile phones or offline?

Yes. The layout adapts for phones with keyboard-friendly editing views. Once loaded, core editing and export keep working without a network connection. For full offline use, run a local copy with Docker or Node (AI features still need access to your configured endpoint).

I used the older GitHub Pages URL. Where are my cards?

Browser storage is tied to the site address, so cards saved on spaceman2408.github.io stay on that origin. Download a Backup ZIP on the old site and Import it on vault.charactervault.app to move your library over.
