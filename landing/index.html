The Card Editor

Built for serious card craft, not cramped text boxes.

Every V2 and V3 field gets a dedicated CodeMirror 6 editor with roleplay-aware syntax coloring, offline spellcheck, live token tracking, and cross-card search.

V2 & V3 Spec

Every card field, unpacked cleanly.

Import a PNG or JSON card and jump cleanly between Name, Description, Personality, Scenario, First Message, Alternate Greetings, Example Dialogue, System Prompt, Post-History, Creator Notes, Tags, and Extensions. V3 fields stay intact through import and export.

  • Color-coded "dialogue", *actions*, and {{char}} / {{user}} macros
  • Bundled offline Hunspell spellcheck that skips macros, code, and URLs
  • Card-wide Find & Replace (Ctrl+Shift+F) with grouped preview and Undo
  • Keeps cursor, scroll position, and undo history as you switch sections

Creator Notes that match SillyTavern

Write Markdown, HTML, and scoped CSS with a resizable live Dock preview. Enable Match SillyTavern to test width presets, dark/light/checkerboard backgrounds, starter snippets, inline color swatches, and CSS formatting — scripts are always blocked, and remote media triggers a privacy notice.

Snapshots & word-level diffs

Save up to 10 snapshots per character, including a protected baseline when you first open a card and automatic save points before Agent edits or Find & Replace. Inspect side-by-side word diffs and roll back the entire card or a single section.

Fast library organization

Browse your cards in a responsive portrait grid with live active/total token estimates. Jump to search with /, click tag chips to filter, sort by Name, Recent, or Created, and pick up instantly with the Continue pill.

SillyTavern Integration

Move cards back and forth without file juggling.

Drag and drop PNG or JSON cards straight onto your vault, or install the companion SillyTavern extension to add Export to CharacterVault right inside SillyTavern's export menu — one click copies the card and opens the import preview with portrait intact.

Local-First Architecture

No account. No cloud database. Full ownership.

CharacterVault runs entirely inside your browser. Your characters, portraits, lorebooks, snapshots, and API keys stay on your device — never uploaded to a CharacterVault server.

Stored in your browser's IndexedDB

There is no sign-up wall, no cloud library, and no ad trackers. Once loaded, core editing, lorebooks, and PNG/JSON export keep working even if your connection drops.

Portable one-file ZIP backups

Click Backup to export every character (embedded PNG or JSON), standalone lorebook, and setting into one ZIP. API keys stay excluded unless you explicitly opt in.

Direct-to-provider AI traffic

Optional AI requests go straight from your browser to the provider or local server you configure. Only the optional NanoGPT subscription-usage check uses a small no-log Cloudflare proxy because NanoGPT blocks that call in browsers. Read Privacy Notice.

Self-Hostable

Run CharacterVault on your own machine.

Prefer a local install for full offline access? Spin it up in seconds with Docker Compose or Node — your data stays in your browser for that origin, and stopping the container loses nothing.

FAQ

Common questions, straightforward answers.

Looking for deeper technical details? Check the full FAQ in the docs or ask in Discord.

Is CharacterVault completely free?

Yes. Every feature is free with no account, trial limit, or paid tier. CharacterVault is open source under the GPL-3.0 license.

Do I need an AI API key or subscription?

No. The card editor, lorebooks, recursion map, Creator Notes preview, snapshots, and import/export all work without AI. When you do want AI tools, connect any OpenAI-compatible provider or a free local server like LM Studio, Ollama, or KoboldCpp.

Where are my cards and API keys stored?

Locally in your browser's IndexedDB and site storage on your device. CharacterVault has no user database and never uploads your cards. AI requests go directly from your browser to the provider you configure.

Are my existing SillyTavern cards and World Info books supported?

Yes. Drag and drop PNG cards with embedded metadata (chara or ccv3), V2/V3 JSON cards, or standalone World Info lorebook JSON. Export back to PNG or JSON anytime, or send cards straight from SillyTavern with the companion export extension.

What happens if I clear my browser data?

Because your vault lives in browser storage, clearing site data removes your local cards, lorebooks, snapshots, and settings. Use Backup in the library header periodically to download a portable ZIP backup you can import on any browser.

Does it work on mobile phones or offline?

Yes. The interface adapts for phones with keyboard-friendly editing layouts. Once loaded, core editing and export continue working without a network connection — or self-host locally with Docker/Node for full offline use (AI tools still require reaching your AI endpoint).

I used the older GitHub Pages URL — where are my cards?

Browser storage is tied to the site address, so cards saved on spaceman2408.github.io stay on that origin. Download a Backup ZIP on the old site and Import it on vault.charactervault.app to bring your library over cleanly.
