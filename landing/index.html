The editor

Every field, with room to write.

Description, personality, scenario, greetings, example dialogue, system prompt, creator notes. Each one gets a real editor instead of a cramped text box.

  • Every V2 and V3 field, alternate greetings included
  • Colors for "dialogue", *actions*, and {{macros}}, plus spellcheck
  • Token estimates on every card, so you know what fits
  • Creator Notes with a safe, live HTML preview

Lorebooks

See how your lore connects.

Lorebooks get their own library beside your characters. Link one book to as many characters as you like, then open the recursion map to see which entries trigger which, and fix the keys right there.

  • Standalone books, linked to many characters and kept in sync
  • A map of every unlock path in the book
  • Every SillyTavern World Info field survives import and export

FAQ

Questions, answered.

Something else on your mind? Ask on Discord or read the full FAQ.

Is CharacterVault really free?

Yes. Every feature is free to use, with no account, trial, or paid tier. The project is open source under GPL-3.0.

Do I need an AI subscription?

No. The editor, lorebooks, import, export, snapshots, and backups all work without AI. If you want AI help, connect any OpenAI-compatible provider, including a free local model through LM Studio.

Where are my cards stored?

In your browser's storage, on your device. CharacterVault has no server that stores cards. Export a card or make a vault backup whenever you want a copy somewhere else.

Will my SillyTavern cards work?

Yes. Import PNG or JSON cards (V2 and V3) and standalone lorebook JSON, edit them, and export them back. The companion extension can also send cards straight from SillyTavern.

Can I use it on my phone?

Yes. The app runs in mobile browsers, with layouts made for small screens. A bigger screen is more comfortable for long writing sessions.

What happens if I clear my browser data?

Clearing site data removes your local library, as it would for any app that stores data in the browser. Use Backup in the library header to save a ZIP of your cards, lorebooks, and settings, and import it to restore.

Can I run my own copy?

Yes. Clone the GitHub repo, run npm install and npm run dev, and it runs on your machine.
